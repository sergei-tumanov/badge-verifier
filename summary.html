Не сработало

❌

Резка по диалогам + повторная транскрибация Yandex даёт лучший текст

Прогон на 77 GT-окнах: token-similarity к проду 0.72–0.86, словарный объём ±8%. Yandex на узком клипе даёт ±тот же текст. Повторная транскрибация выкинута из пайплайна — экономия ₽0.32/мин.

❌

Акустика в первичной LLM-диаризации полной транскрипции

Эксперимент «voice_enrichment_ab» — отрицательный. На широком контексте акустика только мешает: цифры по сегментам разреженно ложатся на 1000+ записей. Plain text работает лучше.

❌

Акустика как вход в детектор диалогов B

B видит только plain text + [CLIP]-метки авторазбивателя. Попытки добавить акустические признаки в input не улучшили детекцию.

❌

Recall-helper промпт для поиска пропущенных диалогов

Эксперимент 5 «recall_minimal_ab» — отрицательный. Доп. промпт «найди ещё диалоги после первичной разметки» не дал прироста recall’а.

❌

Retail-типология (V_USER prompt с категориями продаж)

Эксперимент 3 «retail_prompt_ab» — отрицательный. Привязка к типам диалогов (Apple-консультация / возврат / выдача заказа) не улучшила границы.

❌

Boundaries-only промпт (V_BOUND изолированно)

Эксперимент 4 «boundaries_only_ab» — 5 регрессий на 5 GT-окнах. Фокус на границах без задачи поиска даёт хуже.

Открыто / для дальнейших экспериментов

🔍

Yandex Restore RC (deferred-general:rc) вместо обычного deferred-general

Через GenAI Hub не отдаётся. Нужно прямое обращение к Yandex SpeechKit V3 (есть IAM-токен в most-ai cloud). Может улучшить качество распознавания, особенно на «грязных» сессиях типа s4.

🔍

Word-level сплит вместо проп-char
